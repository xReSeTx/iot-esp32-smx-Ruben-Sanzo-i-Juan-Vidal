GreenFarm – Sistema de Reg Intel·ligent

Sistema basat en ESP32 i sensor LM35 que activa el reg automàticament quan la temperatura supera un llindar definit. Les dades es mostren en temps real pel Monitor Sèrie.

Hardware:
ESP32
Sensor LM35 (GPIO 34)
