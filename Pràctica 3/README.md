Aquest projecte consisteix en el desenvolupament d'un sistema de monitorització de temperatura utilitzant una ESP32 com a servidor web.

L'objectiu és mostrar en una pàgina web les dades de la temperatura llegides pels sensors connectats a la placa.

Objectius:

-Connectar una ESP32 a una xarxa WiFi.
-Crear un servidor web accessible des d'un navegador.
-Llegir dades de temperatura mitjançant un sensor LM35.
-Mostrar les dades en temps real a la pàgina web.
-Gestionar el projecte utilitzant GitHub Issues i GitHub Projects.
